# helper-git-rep 🚀

**Автоматизированный агентный конвейер для переноса портфолио на GitHub**

## 📌 Проблема
Разработчики и IT-специалисты часто имеют десятки локальных проектов, скриптов и прототипов, которые представляют ценность, но остаются неопубликованными. Процесс ручной очистки кода, написания документации и инициализации репозиториев слишком утомителен и занимает много времени. Этот «долг по портфолио» ограничивает профессиональную видимость специалиста.

## ✅ Решение
`helper-git-rep` — это интеллектуальный инструмент автоматизации, который превращает сырые локальные директории в профессиональные репозитории на GitHub. Вместо простого копирования файлов он использует конвейер на базе LLM-агентов, чтобы каждый опубликованный проект соответствовал индустриальным стандартам.

### Основной рабочий процесс (Workflow)
Инструмент следует строгому четырехэтапному конвейеру:
1. **Анализ**: Сканирует структуру проекта, определяет основной язык программирования и суть проекта.
2. **Очистка**: Удаляет временные файлы, логи и чувствительные данные, автоматически создавая подходящий `.gitignore`.
3. **Генерация**: Использует большие языковые модели (LLM) для создания содержательных файлов `README.md`, описаний проекта и документации.
4. **Публикация**: Инициализирует Git, фиксирует изменения и создает публичный репозиторий на GitHub через `gh` CLI.

## 🛠 Технологический стек
- **Backend**: Python 3.x, Flask (API и веб-интерфейс)
- **Автоматизация**: GitHub CLI (`gh`)
- **Интеллект**: Интеграция с LLM (через `LLMClient` и `OrchestratorAgent`)
- **Frontend**: HTML/CSS/JS (Веб-дашборд с визуализацией прогресса)

## 🚀 Установка и использование

### Предварительные требования
- Установленный и авторизованный [GitHub CLI (`gh`)](https://cli.github.com/).
- Python 3.8+
- Валидный API-ключ для используемой LLM.

### Настройка
1. Клонируйте этот репозиторий:
   ```bash
   git clone https://github.com/your-username/helper-git-rep.git
   cd helper-git-rep
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Настройте параметры LLM в директории `config/`.

### Запуск инструмента
Запустите сервер Flask:
```bash
python main.py
```
Откройте дашборд по адресу `http://127.0.0.1:5000`, укажите путь к вашему локальному проекту и позвольте агенту сделать всё остальное.

## 📁 Структура проекта
- `app/core/`: Логика агентов (`OrchestratorAgent`) и клиент LLM.
- `app/web/`: Шаблоны фронтенда и статические ресурсы.
- `in-rep/`: Очередь проектов, ожидающих обработки.
- `passed-rep/`: Архив проектов, которые были успешно перенесены на GitHub.

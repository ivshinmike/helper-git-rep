# 🌐 Руководство по использованию веб-интерфейса Helper Git Rep

Веб-интерфейс предоставляет удобную панель управления для автоматизации переноса локальных проектов на GitHub.

## 🚀 Быстрый старт

1. **Запуск сервера**: 
   Запустите основной файл приложения:
   ```bash
   python main.py
   ```
2. **Открытие панели**: 
   Откройте браузер и перейдите по адресу: [http://127.0.0.1:5000/](http://127.0.0.1:5000/)

## 🛠 Как запустить миграцию

В левой части экрана находится форма **"Новая миграция"**:

- **Локальный путь к проекту**: Укажите полный путь к папке с кодом на вашем компьютере (например, `D:\projects\my-app`).
- **Имя репозитория на GitHub**: Введите название, которое будет у вашего нового репозитория.
- **Принудительный перезапуск**: Отметьте этот пункт, если хотите начать процесс заново, даже если проект уже был частично обработан ранее.
- **Язык**: Переключатель в верхней части страницы позволяет выбрать язык генерации документации (RU/EN).

Нажмите кнопку **"Запустить агентов"**, чтобы начать процесс.

## 📊 Мониторинг процесса

После запуска в правой части экрана активируется панель **"Активность агентов"**:

- **Индикатор прогресса**: Вы увидите движение по четырем ключевым этапам:
    1. `Анализ` $\to$ 2. `Очистка` $\to$ 3. `Документация` $\to$ 4. `Публикация`.
- **Статус**: Текущее состояние (например, "Агенты мобилизуются...") отображается в нижней части панели.
- **История**: В таблице **"История миграций"** сохраняются данные обо всех запущенных процессах и их финальном статусе.

## ⌨️ Горячие клавиши

Для быстрого переключения языка интерфейса используйте комбинации:
- `Alt + R` — Русский язык.
- `Alt + E` — English language.
